# Принято: случайные вопросы по текущему этапу

Основание: план «Подсказки вопросов по этапам стажировки», явно утверждённый пользователем 12 ноября 2026 года. Пользователь отдельно уточнил: руководитель не связан с этими кнопками; это автоматическая часть продукта. Подборка меняется только при смене этапа, без ежедневного обновления и без обновления после ответа.

## Поведение

Бот выбирает три разных вопроса из встроенного набора этапа. Выбор и порядок сохраняются для конкретного стажёра. Нажатие отправляет вопрос обычным сообщением в личный чат; произвольный ввод остаётся доступен. Перезагрузка, повторный вход, ответ, отметки, просмотр старых сообщений и правки черновика не меняют подборку. Публикация или переключение варианта при том же текущем этапе также сохраняет выбор.

Этап определяется фактическими датами блоков действующего опубликованного сценария. До первого этапа используются стартовые вопросы. Без опубликованного сценария кнопки скрыты. На этапах обучения/практики появляются вопросы «Как взять отгул?» и «Как взять отпуск?». У финальных этапов собственные вопросы о результатах, передаче и продолжении работы. Полные восемь наборов, по четыре вопроса каждый, реализованы в `frontend/src/suggestions.ts` согласно утверждённой таблице.

## Технические конкретизации локального прототипа

- В `Runtime` добавлено необязательное `suggestions`: идентификатор текущего блока/предстарта, тема и выбранные вопросы. Схема и ключ localStorage v3 сохраняются. Старые записи без поля получают подборку без сброса истории, планов или отметок.
- В новых готовых блоках есть внутреннее поле `stageKind`, не выводимое в конфигуратор. Копии наследуют его. Прежние ID и ID копий распознаются по префиксу, неизвестные старые блоки получают нейтральную тему помощи.
- Выбор производится один раз и сохраняется тем же механизмом, что остальное состояние. На повторном проходе без смены этапа функция ничего не изменяет и не вызывает генератор случайных чисел.
- Переключение на ещё один блок той же темы выбирает отличающийся набор, когда в пуле есть другой вопрос. Старое название/снимок сообщения не используется для определения текущего этапа.

## Ответы и границы

Вопрос про отпуск не является действием по его оформлению и не задаёт корпоративные правила. Используется существующий механизм доступных материалов. Если инструкции нет, бот сообщает об отсутствии подтверждённого ответа и направляет к HR; недоступные/исключённые источники не цитируются. Подключение настоящего RAG/LLM этим изменением не выполняется.

Проверка переходов по будущим датам выполняется на отдельном локальном origin, чтобы не добавлять будущие чекпоинты в пользовательскую историю основного прототипа.
