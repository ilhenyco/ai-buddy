# Принято: список сценариев и несколько персональных вариантов

Основание: пользователь согласовал и поручил реализовать план «Список сценариев и возврат к черновикам» 12 ноября 2026 года. В уточнениях выбраны персональные сценарии, все статусы, несколько стажёров и несколько вариантов для одного стажёра.

Вкладка руководителя открывает список, из него открывается рабочий черновик или создаётся новый. Редактор содержит название и возврат к списку. Черновики автоматически сохраняются независимо, включая неполные. Фильтры черновиков и опубликованных могут пересекаться, когда опубликованный вариант содержит неопубликованные правки.

Один опубликованный вариант на стажёра используется для сообщений. Публикация другого требует явного подтверждения замены. Старый остаётся доступен, переписка и отметки сохраняются. При смене варианта не досылаются этапы с датой не позднее даты переключения; после этой даты сообщения идут из нового расписания. Повторная публикация того же варианта сохраняет его границу и не меняет уже отправленные снимки.

Локальная реализация: React/TypeScript, коллекция сценариев, ID действующего варианта по стажёру, отдельные истории и отметки, события scenario ID + block ID. `homych.frontend.bot.v3` восстанавливается из v2 при первом запуске. Исходная запись v2 не удаляется миграцией. Проблема чтения приостанавливает запись, проблема сохранения отображается с повторной попыткой. Данные открытой вкладки не теряются при ошибке записи.

Два дополнительных синтетических стажёра: Маша Петрова и Илья Смирнов. Выбор стажёра для просмотра находится в панели демонстрации. Создание сценария никому не назначает рассылку до публикации. Уже опубликованный вариант нельзя перенести другому стажёру, чтобы не смешать историю; для другого участника создаётся новый.

Удаление, общие шаблоны, backend/auth и фоновая серверная доставка этим изменением не реализуются. Прежние снимки экрана и файл с шестью кадрами продукта показывают дизайн до появления списка сценариев.
