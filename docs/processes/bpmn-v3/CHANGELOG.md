# Изменения BPMN от версии 2 к версии 3

## Редакция 3.1 · 12 ноября 2026

Текущая передача: требования 0.4, 47 FR и 40 строк снимка. P00 показывает восемь независимых блоков шаблона. P01 включает библиотеку/поиск, новый и сохранённый draft, autosave/ошибку, возврат, проверку и подтверждение замены active. P14 включает стабильные случайные подсказки текущего этапа; OQ01 закрыт, личный диалог приватен. P15 читает active/revision/cutoff. Новые изображения строятся из BPMN DI; полный актуальный атлас включён в ai-buddy-team-specification.docx. XSD, графовая проверка и 55 семантических проверок проходят. Приведённая далее таблица — история исходной переработки 11 ноября, её прежние статусы предложений не отменяют решения 12 ноября.

## История первоначальной редакции 3

Основание — функциональные требования 0.2 и уточнения концепции от 11 ноября 2026 года.

| Процесс | Изменение |
|---|---|
| P00 | Последовательность завершения бизнес-этапов заменена независимыми календарными ветками рассылки. Завершение ветки означает обработку сообщения, а не окончание работы людей. |
| P01 | Обязательный AI черновик заменён сборкой готовых блоков руководителем. Предпросмотр охватывает сообщения трём ролям. Проверка полноты и версии отмечены как предложения. |
| P02–P03 | Переписка и сообщения заменяют обязательный маршрут отдельных карточек. Формальные отметки отделены от периодов. |
| P04 | Основной путь ведёт по внешней ссылке при поддержке бадди. Вызов сервиса внутри продукта представлен отдельной условной веткой. |
| P05–P06 | Сохранена логика единственной операции, номера, статуса и восстановления. Весь объём явно условен по OQ08. |
| P07 | Общие инструкции доступны в сообщении. Проверка закрытого материала сохранена условно; она не влияет на календарь. Открытие ссылки не создаёт отметку. |
| P08–P09 | Сохранена ручная работа людей. Её результат не является условием запуска следующего периода. |
| P10–P11 | Убрана обязательная продуктовая помощь с генерацией повестки и выступления. Бот напоминает, участники готовят результаты вне продукта. |
| P12 | Итоги и передача остаются ручными действиями без требования загрузить отчёт в приложение. |
| P13 | Убрана зависимость от сохранённого решения о найме. После окончания приходит календарное напоминание со ссылками и контактами. |
| P14 | Явно выделен поиск RAG после проверки прав. Ответ идёт стажёру; возможность распространения личных AI ответов остаётся OQ01. |
| P15 | Добавлен общий процесс сообщений по ролям без обращения к личному чату и без проверки заполнения чек-листа. |
| P16 | Добавлено предложение обработки одной доставки, подтверждения и сбоя. Канал и интервалы повторов не назначены произвольно. |
| P17 | Добавлен предложенный процесс обновления источников RAG. Владелец материалов не назначен автоматически HR. |

Источники версии 2 и прежний большой Word документ сохранены. Новая поставка содержит отдельный актуальный сборник схем. Не переносите старые задачи по совпадающему ID узла без проверки: бизнес-смысл некоторых узлов изменён, например P01_draft и P13_show. Для передачи в разработку используйте таблицу требований версии 3.

Новые обязанности HR в интерфейсе, массовое назначение шаблонов, канал бота и пересылка AI ответов не считаются утверждёнными. Они остаются в OQ01–OQ08 и в статусах требований.
