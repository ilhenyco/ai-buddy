# FRONT для серверной команды

Актуально: 12.11.2026. Локальный React/TypeScript-прототип. Основные материалы — [концепция](../../docs/product/team-specification.md), [полный каталог функций](../../docs/product/frontend-functional-specification.md), [подключение сервера](../../docs/architecture/server-handoff.md), [проект OpenAPI](../../docs/architecture/openapi.yaml).

`src/App.tsx` — интерфейс/локальные обработчики; `domain.ts` — шаблоны, ролевые пункты, имитация ответов/доступа; `scenarios.ts` — v3, библиотека, публикация и доставка; `suggestions.ts` — темы и стабильные тройки; `ui.tsx` — окна/фокус. `main.jsx → App.jsx → App.tsx` — действительная цепочка входа, JSX-файлы не удалять как якобы устаревшие. CSS подключаются слоями; ассеты и Onest находятся в public.

Личный чат виден только стажёру — принято, OQ01 закрыт. Бадди/руководитель видят свои плановые действия. Несколько персональных сценариев и стажёров реализованы локально; роль HR/владелец материалов ещё предложения. Реальные auth, Go API, PostgreSQL, RAG, Qwen/DeepSeek, MCP, transport и HTTP-мок доступа пока отсутствуют. Нельзя переносить demo-switch в production как разрешение читать чужой профиль.

`localStorage` и setTimeout требуется заменить сервисным слоем по server-handoff. В `frontend/design/screenshots` есть снимки разных редакций; в новом Word у каждого показанного экрана явно подписана актуальность. Полезные исторические QA сохранены, но ранние предположения не заменяют сегодняшнюю спецификацию.

Проверки: `npm ci`, `npm run check`, `npm test`, `npm run test:sites`, `npm run build`. Запуск: `npm run dev -- --host 127.0.0.1 --port 4173` на Node 22.18+. Доступы к приватному репозиторию выдаёт владелец.
