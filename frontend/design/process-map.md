# BPMN → интерфейс Хомыча

**Актуально 12.11.2026:** P01 включает список/поиск/черновики/autosave/замену; P14 — стабильные подсказки этапа и приватный диалог. Точная модель — output/bpmn-v3/models, полный каталог — docs/product/frontend-functional-specification.md. Старые ссылки на требования 0.2 ниже исторические.


Уточнение от 12 ноября: бот сам пишет в одну историю по срокам. Навигация по периодам и отдельная панель следующей точки исключены. Бадди и руководитель получают соответствующие чек-листы совместных действий.

Основа: BPMN **P00–P17 v3**, функциональные требования **0.2**. Все процессы представлены интерфейсом, сообщением, внешним переходом или отдельно обозначенной условной веткой. Это покрытие дизайном, не утверждение о готовности серверных бизнес-процессов.

| BPMN | Как смотреть / что спроектировано | Граница реализации |
|---|---|---|
| P00 Весь путь | Автоматические сообщения в одной истории; следующая точка строкой в конце сообщения | Локальная проверка даты, без выбора периода в чате; промышленного планировщика нет |
| P01 Настройка | Руководитель → Сценарий: 6/9 месяцев, участники, даты, готовые блоки, порядок, тексты, ссылки, предпросмотр, публикация | Локальные черновик и версия; массовое назначение не добавлено |
| P02 Первый вход | Уже опубликованный план, приветствие, личный чат, контакты; состояние без плана | Вход и роли демонстрационные, SSO нет |
| P03 Знакомство | Первый день / Первая неделя → команда, каналы, бадди, формальные отметки | Реальные чаты не заданы; памятки и контакты синтетические |
| P04 Доступы | Первая неделя → Инструкция по доступам → помощь бадди и рабочая ссылка | Основной сценарий внешний. Условная интеграция OQ08 выключена по умолчанию |
| P05 Подтверждение заявки | Состояния → Условная интеграция → Открыть заявку: ресурс, обоснование, подтверждение человеком | Только демонстрационная операция; модель не отправляет её |
| P06 Статус заявки | Номер DEMO-1042, ожидание, одобрение, отказ, неизвестный результат, повтор той же операции | Тестовые переключатели; внешнего вызова нет. Не блокирует периоды |
| P07 Первая задача | Первая неделя → Открыть инструкцию → памятка и помощь бадди | Постановка и работа снаружи. Защищённая демопостановка видна только после approved в OQ08 |
| P08 Цели и курсы | Цели и обучение → материалы курсов, контакт руководителя, помощь бадди | Прохождение и оценка вне продукта; отметка не подтверждает корпоративное событие |
| P09 Практика | Учебная практика → памятка и обсуждение с бадди | Учебная работа вне бота; блок можно настроить/удалить |
| P10 Экватор | Промежуточные результаты, контакт бадди и руководителя; отдельные напоминания им | Встреча, презентация и выводы снаружи; отчёт не требуется для следующей даты |
| P11 Подготовка финала | Подготовка к финалу → напоминание о формате итогов, встрече и дальнейших шагах | Кадровых обещаний и автоматического решения нет |
| P12 Итоги и передача | Итоги и передача → сообщения и памятки | Оценка, встреча и решение о найме принимаются людьми вне продукта |
| P13 После стажировки | После стажировки → передача задач и контакт HR | Рассылка не зависит от решения о найме |
| P14 Ответ AI | Свободный чат только у стажёра, основание ответа, просмотр источника, нехватка данных и недоступная модель | Локальная имитация. Настоящие модель, retrieval и права подключаются сервером |
| P15 Сообщения по ролям | Один период → разные тексты стажёру, бадди и руководителю; предпросмотр трёх получателей | Только сообщения сценария, личный вопрос стажёра не пересылается. OQ01 открыт |
| P16 Доставка | Уведомления, настройки звука, состояние сбоя и повтор | Предложение по деталям доставки; реальных push/фонового worker нет |
| P17 Материалы | Материалы: чтение, добавление, обновление, индексация, исключение, ошибка обновления | Предложение по операторскому интерфейсу, владелец не выбран. Поиск имитируется |

## Основные экраны

| Экран | Роли | Важные состояния |
|---|---|---|
| Единая переписка бота | Стажёр | Приветствие; текущий/другой период; отмеченный пункт; история; ответ/источник; loading; нет основания; недоступна модель; нет плана; ошибка загрузки |
| Сообщения о помощи | Бадди, руководитель | Соответствующий чек-лист совместных действий, стажёр и дата, отсутствие AI-композера и личного диалога |
| Конструктор | Руководитель | Черновик, редактирование блока/получателя/задачи, готовые блоки, 6/9 месяцев, предпросмотр, подтверждение публикации, ошибка полей |
| Контакты, памятки, источники | Участники в доступном контексте | Popup на широком экране / нижняя панель в узком; внешняя ссылка ещё не подключена |
| Материалы | Руководитель / HR как вариант | Поиск, готовый источник, добавление, обновление, подготовка, ошибка, исключение |
| Уведомления и настройки | Все роли | Собственное сообщение, повтор доставки, звук, тест сигнала |
| Заявка / статус | Условный сценарий стажёра | Подтверждение, ожидание, unknown, denied, approved; одна операция |
| HR | Вариант | Организационные сведения и материалы, явная пометка о несогласованной роли |

## Требования и что они означают для разработчика

| Группа FR 0.2 | Поверхность дизайна | Что ещё нужно для работающего продукта |
|---|---|---|
| FR-PL-01–07 | Конструктор, черновик, валидация, публикация, сохранение снимков показанных сообщений | Серверные версии, права владельца, транзакции, пересчёт будущих доставок |
| FR-IN-01–06 | Сообщения, инструкции, чат, отметки, история и ссылки | Профили и хранилище на сервере, реальная модель и корпоративные адреса |
| FR-CY-01–06 | Автоматические сообщения по датам, отметки без блокировки | Планировщик, часовой пояс, отдельная сущность отметки и внешнего результата |
| FR-SU-01–05 | Соответствующие пункты бадди/руководителю, контекст исходного пункта стажёра, напоминания о встречах | Политика получателей, переходы при замене бадди, решение OQ01 |
| FR-KB-01–06 | Ответ/источник/fallback и вариант управления материалами | Авторизованный retrieval до модели, версии индекса, владелец знаний |
| FR-NT-01–04 | Уведомления, звук, один показанный снимок, повтор | Канал доставки, очередь, идемпотентность, повторы отдельно по адресату |
| FR-AC-01–02 | Отдельные представления и личный диалог | Настоящая серверная проверка пользователя/команды/стажировки; переключатель макета не является контролем доступа |
| FR-EX-01–03 | Внешние действия, результаты снаружи, условный прямой вызов | Корпоративные ссылки и, только после решения OQ08, сервис заявки и хранение состояния |
| FR-HR-01–03 | Помеченный вариант организационных материалов | Сначала согласовать ответственность и объём сообщений HR |

См. исходный документ требований для статуса каждого отдельного FR: не вся строка диапазона согласована. OQ01–OQ08 сохраняются открытыми. У макета нет полномочий менять кадровые процессы, оценивать результат стажёра или разрешать доступ на основании галочки.
